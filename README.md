# NPVA - Network Port and Vulnerability Auditor

NPVA is a web-based cybersecurity tool that scans network ports, detects services, maps vulnerabilities using CVE databases, and integrates Wazuh alerts.

## Features
- Nmap port scanning
- Service detection
- Vulnerability mapping (Vulners API + fallback)
- Wazuh alert monitoring
- Report generation (HTML, PDF, CSV)

## Technologies Used
- Python (Flask)
- Nmap
- SQLite
- Wazuh
